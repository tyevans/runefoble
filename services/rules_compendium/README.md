# Rules Compendium & Automated Encounter Builder Microservice

TTRPG rules compendium and automated Challenge Rating (CR) encounter builder for Runefoble.

Powered by `redstring` for hybrid BM25 and semantic vector retrieval and `eventsource-py` for event sourcing. Exposes public REST endpoints and FastMCP tools for sub-50ms rule lookups and mathematical encounter balancing.
