# US-0020 — DM Vocal Modulator with Real-Time NPC Formant Filtering

## User Story

**As a** DM voicing diverse NPCs across 4-hour sessions (Evelyn),  
**I want to** apply real-time DSP vocal modulation to my live microphone stream,  
**So that** I can portray dragons, goblins, and ethereal spirits convincingly without vocal fatigue.

## Acceptance Criteria

1. **One-Touch Voice Presets**: Evelyn can toggle DSP presets ("Ancient Dragon", "Goblin Skulker", "Celestial") via UI or hotkey.
2. **Low Latency Processing**: Vocal conditioning and pitch/formant shifting process with under 50ms latency in the voice pipeline.
3. **Toggle Indicator**: Live visual indicator signals which voice filter is currently active on the DM's outgoing voice stream.
