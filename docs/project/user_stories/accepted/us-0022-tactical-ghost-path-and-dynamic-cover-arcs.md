# US-0022 — Tactical Ghost Path Trajectory and Dynamic Cover Arcs

## User Story

**As a** player maneuvering in tactical combat (Marcus),  
**I want to** see an animated ghost trajectory with threat warnings and cover arcs as I speak,  
**So that** I understand opportunity attack risks and cover advantages before finalizing my move.

## Acceptance Criteria

1. **Ghost Trajectory Preview**: Spoken movement prompts project a semi-transparent ghost token along the intended path.
2. **Threat Zone Highlighting**: Cells triggering potential opportunity attacks or hazard damage flash with warning highlights.
3. **Dynamic Cover Arcs**: Visual indicators display half-cover and three-quarters cover status relative to known enemy tokens.
