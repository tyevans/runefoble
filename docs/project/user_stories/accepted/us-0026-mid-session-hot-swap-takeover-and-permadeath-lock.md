# US-0026 — Mid-Session Hot-Swap Takeover and Permadeath Safety Safeguards

## User Story

**As a** busy player who might join late or miss entirely (Sarah),  
**I want to** seamlessly assume control of my character mid-session and have safeguards against permadeath while absent,  
**So that** my character is protected and I can jump right into the game without disrupting the table.

## Acceptance Criteria

1. **Mid-Session Hot-Swap**: When Sarah logs into an active session, clicking "Take Control" smoothly transitions the character from AI stand-in to live player control.
2. **Permadeath Safeguard**: Configurable rule prevents character death or permanent loss of legendary gear while controlled by an AI stand-in (character falls unconscious or stabilizes).
3. **Turn Order Continuity**: Hot-swapping preserves existing initiative order and round status without reloading the encounter.
