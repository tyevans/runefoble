# Backlog Management Guide

This directory holds the engineering task queue for Runefoble.
Tasks move through three lifecycle stages:
- `proposed/`: Unrefined ideas and candidate work items.
- `refined/`: Architectural impact review completed, governing ADRs/PRDs cited, testable definition of done established.
- `complete/`: Verified against tests, linted, committed, and integrated into the codebase.

## Picking Work
Always pick the highest-priority item from `docs/project/backlog/PRIORITY.md` that is currently in `refined/`.
