# TASK-0137: Autonomous NPC Faction Agendas Radar & Intelligence Bulletin Microfrontend

## Status
Refined

## Summary
Build the `<runefoble-faction-radar>` microfrontend in `services/the_watcher/ui/src/` visualizing NPC faction power dynamics, territory control, secret DM intelligence bulletins, and tick-by-tick timeline events with Bauhaus design tokens and Storybook stories.

## Problem Statement
TASK-0126 established the backend autonomous faction simulation engine and domain events (`WorldTickExecuted`, `GeopoliticalShiftOccurred`). Game Masters and players need an interactive interface (PRD-0001, US-0057) to visualize faction influence shifts, monitor inter-faction rivalries, inspect evolving tavern rumors, and review secret DM intelligence bulletins.

## Governing Architecture & ADRs
- **ADR-0001: SpiceDB Zanzibar Object-Level Authorization**: Redacts private DM intelligence briefings from player participants while revealing public rumors.
- **ADR-0006: Redis Streams Event Bus**: Listens for `WorldTickExecuted` and updates the radar view in real time.
- **ADR-0013: Microfrontend Architecture and Service Component Vendoring**: Self-contained component package vendored strictly inside `services/the_watcher/ui/src/` with Shadow DOM and Bauhaus design tokens.

## Detailed Specification & Implementation Plan
1. **Faction Radar Microfrontend Component (`services/the_watcher/ui/src/runefoble-faction-radar.ts`)**:
   - `<runefoble-faction-radar>` Lit component displaying SVG/Canvas radar chart of faction influence (0-100), territorial control chips, and disposition gauges.
2. **DM Intelligence Bulletin Panel**:
   - Private briefing drawer detailing background faction clashes, territorial conquests, and strategic moves generated by `bulletin.py`.
3. **Public Tavern Rumors Feed**:
   - Filtered public news stream showing diegetic rumors generated by world ticks.
4. **Storybook Verification & Component Manifest**:
   - `runefoble-faction-radar.stories.ts` with stories rendering multiple faction configurations, DM secret views, and public player views.
   - Served via `/the_watcher/ui/manifest`.

## INVEST Criteria Evaluation
- **Independent (I)**: Interacts strictly through `/api/v1/campaigns/{id}/factions` and `/world-ticks/latest` public REST endpoints.
- **Negotiable (N)**: Chart visualization style and timeline density can be customized.
- **Valuable (V)**: Brings autonomous world simulation to life visually for DMs and players alike.
- **Estimable (E)**: Builds on existing the_watcher microfrontend architecture.
- **Small (S)**: Bounded strictly to `services/the_watcher/ui/src/`; files < 350 lines.
- **Testable (T)**: Frontdoor tests verify UI manifest, role redaction, and radar rendering.
